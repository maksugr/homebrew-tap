# homebrew-tap

Homebrew tap for tools by [Roman Ponomarev](https://github.com/maksugr).

## Install

```bash
brew tap maksugr/tap
brew install <formula>
```

Or one-shot:

```bash
brew install maksugr/tap/<formula>
```

## Formulae

- [`acp-devtools`](Formula/acp-devtools.rb) — visual debugger and inspector for the Agent Client Protocol (ACP). [Source repo](https://github.com/maksugr/acp-devtools).
